## What's in this repo

Each course folder contains the workflows I built during the course, exported as JSON so they can be imported straight into n8n, plus screenshots of each workflow running.

```

│   └── screenshots/

```

## How to import a workflow

1. Open your n8n instance and create a new workflow.
2. Click the **...** menu, then **Import from File**, and select a JSON file from any `workflows/` folder.
3. Add your own credentials where a node asks for them. No credentials are stored in this repo.
